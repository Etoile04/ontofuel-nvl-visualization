# OntoFuel NVL Visualization

OntoFuel 本体可视化应用 - 使用 Neo4j NVL

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm start

# 访问 http://localhost:3000
```

## 功能

- ✅ 849 个节点可视化（139 类 + 710 个体）
- ✅ 1003 个关系展示
- ✅ 搜索和过滤
- ✅ 4 种布局切换
- ✅ 节点详情查看
- ✅ 数据导出

## 技术栈

- React 18
- TypeScript 5
- Neo4j NVL
